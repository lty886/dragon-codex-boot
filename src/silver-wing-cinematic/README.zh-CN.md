## 要真正完成角色运动，需补充其中一种
1. 最方便：同一角色、你有使用权的干净动画 MP4，建议 H.264 /1920×1080 /24或30fps，包含全身出场、转身、眨眼、挥手，以及发裙翼尾运动。不要含手机录屏界面、水印或第三方音乐。接收后按实际视频时长播放，不强行加速。
2. 可编辑方案：Live2D 模型和贴图（model3.json、moc3、textures、motions、physics）并具备所需动作；大角度完整转身还需要额外多视角或 3D 模型。
3. 真正转身方案：同角色的已绑定骨骼 VRM/GLB 模型、贴图、表情、挥手/转身动画，并且发裙翼尾可独立驱动。
4. 只有 PSD/PNG 分层时：需要前后发束、脸/眼白/虹膜/上下眼皮、开闭嘴、手臂/前臂/手掌、上身、裙摆多层、左右翼膜与翼骨、尾部分节，含遮挡部位补画及侧背视图；还必须进行绑定与动作制作，分层本身不等于完成转身。
